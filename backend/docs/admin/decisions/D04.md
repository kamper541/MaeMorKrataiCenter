# Decision D04: Public `backend-client` Security Baseline (Phase 1 Account-less Access)

- **Date**: 2026-11-15
- **Spec**: [SPEC-001](../specs/SPEC-001-infra-scaffold.md)
- **Status**: APPROVED

## 1. Context & Problem Statement
In Phase 1, customers do not have user accounts, so `backend-client` exposes public HTTP endpoints consumed by the static Next.js export (`frontend-client`). Without strong edge and application defenses, public endpoints risk scraping, DDoS/abuse, cross-origin misuse, and payload/error leaks.

## 2. Decision
Bake a defense-in-depth security layer into `backend-client` from `SPEC-001`:
1. **Strict Environment CORS Allowlist**: Explicit allowed origins per environment (`dev`, `staging`, `prod`); never wildcard `*` with credentials.
2. **Cloudflare Native Rate Limiting (`[[ratelimits]]`)**: Enforce per-IP/route rate limits using `env.rate_limiter(...)` (`429 Too Many Requests` on breach).
3. **Turnstile Verification Guard**: Implement a reusable Cloudflare Turnstile siteverify middleware/extractor ready for state-changing public routes in `SPEC-002+` (e.g., card draws).
4. **Input, Header & Error Hardening**: Enforce strict request body size caps, standard security headers (`X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Cache-Control: no-store` on dynamic/error responses), and a uniform non-leaking JSON error envelope (`request_id`, `code`, `message`—never internal SQL/stack traces).
5. **Zero Public LLM Execution**: No AI/LLM endpoints are exposed publicly in `SPEC-001`.

## 3. Rationale
- **Security (#1)**: Mitigates OWASP A01, A03, A04, A05, and A09 on unauthenticated public routes.
- **Technical Debt (#2)**: Centralizing CORS, rate limits, Turnstile, and error mapping in Axum middleware prevents per-handler drift in `SPEC-002+`.
- **Speed (#3)**: Leverages native Cloudflare `[[ratelimits]]` and Turnstile with minimal runtime overhead.

## 4. Consequences
- Every `backend-client` route inherits global rate limiting, strict CORS, body size limits, and structured error sanitization by default.
- Turnstile secret keys MUST reside in Wrangler Secrets (`dev` test key locally, real secrets in `staging`/`prod`).
