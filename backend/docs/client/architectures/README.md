# Project Architectures

This directory maintains the project's living architecture:
- `tech-stack.md`: Core programming languages, frameworks, runtime versions, package managers.
- `database.md`: Database engines, schemas, caching, migration policies.
- `cloud-infrastructure.md`: Cloud providers, serverless/containers, deployment topology, networking.
- `system-topology.md`: Component relationships, external service integrations.

> **Note**: Update these files whenever an architectural decision or new dependency is introduced via `NN_DOCUMENTATION.md`.
