# Living Project Knowledges

This directory stores long-term, living documentation for all features built in this project:
- `features/`: Comprehensive feature manuals generated automatically by each plan's final `NN_DOCUMENTATION.md` task (e.g. `main-chat.md`, `authentication.md`).
- Each feature doc covers:
  1. Overview & Architecture
  2. How to Use / API Specs
  3. Security & Operational Invariants
  4. References to linked decisions in `docs/decisions/`

> **Roadmap Note**: This directory is designed to be ingested into a **Knowledge Graph** in Phase 2.
